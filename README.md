# Ozonologist

AI-ассистент для продавцов Ozon: чат уровня ChatGPT, который получает реальные данные
магазина через Ozon Seller API и анализирует их с помощью GPT.

> 📌 Полное состояние проекта, архитектура, что сделано и что осталось —
> в [PROGRESS.md](./PROGRESS.md). Читай его первым при продолжении работы.

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # затем впиши ключи в .env.local
npm run dev                  # → http://localhost:3000
```

### Ключи (.env.local)

- `OPENAI_API_KEY` — обязателен (чтобы чат отвечал).
- `OZON_CLIENT_ID`, `OZON_API_KEY` — для реальных данных магазина.
  Без них приложение работает на **мок-данных** (тестовый магазин) — код тот же.

Подробности по переменным — в [.env.example](./.env.example).

## Как это работает

Браузер → `/api/agent-chat` → **Diagnostic Runtime** (детерминированный):
вопрос сопоставляется с юнитом знаний → метрики собираются из Ozon через
Tool Registry → Formula Engine считает → правила юнита выносят диагноз.
GPT подключается последним и только формулирует уже готовый вывод.

GPT не выдумывает цифры, потому что **не считает их**: он получает посчитанные
факты и диагноз, а всё вычисление живёт в `knowledge/formulas.yaml` и
`src/knowledge/formulas.ts`. Метрика без данных помечается `unknown` и остаётся
«нет данных» — не нулём.

Вопрос без указания товара разбирается как обход всего ассортимента: каждый юнит
применяется к каждому SKU, находки ранжируются по критичности.

## Полезные команды

```bash
npm run dev        # дев-сервер
npm run build      # прод-сборка
npm run eval       # офлайн-проверка правил диагностики (без LLM и без сети)
npm run test:ozon  # проверить подключение к Ozon API
```
